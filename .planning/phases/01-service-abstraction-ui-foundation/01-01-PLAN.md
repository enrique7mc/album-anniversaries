  <action>
Create `src/app/services/music-service.token.ts` with:

1. Import InjectionToken from '@angular/core'
2. Import MusicService from './music-service.interface'
3. Export const MUSIC_SERVICE = new InjectionToken<MusicService>('MusicService')

CRITICAL: Do NOT use providedIn option - the token will be configured in app.module.ts via factory provider.

This file must be separate from the interface to avoid circular dependencies:
- Interface file: defines the contract
- Token file: defines the DI token that references the interface

Example pattern:
```typescript

import { MusicService } from './music-service.interface';

export const MUSIC_SERVICE = new InjectionToken<MusicService>('MusicService');
```
