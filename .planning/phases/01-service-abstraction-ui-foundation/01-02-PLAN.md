
   - Change: `private spotifyService: SpotifyService`
   - To: `@Inject(MUSIC_SERVICE) private musicService: MusicService`

3. Update all usages of `this.spotifyService` to `this.musicService`:
   - `this.spotifyService.loadArtistsWithAlbums` -> `this.musicService.loadArtistsWithAlbums`
   - `this.spotifyService.artists` -> `this.musicService.artists`

4. KEEP SpotifyService import for static method access:
   - Keep: `import { SpotifyService } from './spotify.service';`
   - Static methods like `SpotifyService.albumHadBirthdayPastWeek` remain unchanged
   - Static methods like `SpotifyService.albumReleasedPastYear` remain unchanged
   - Static methods like `SpotifyService.albumHadBirthdayPastMonth` remain unchanged

The component should:
- Inject MusicService via MUSIC_SERVICE token (for instance methods)
- Still import SpotifyService class directly (for static utility methods)

This separation is intentional - static utility methods are NOT part of the MusicService contract.
