<task type="checkpoint:human-action" gate="blocking">
  <name>Task 1: Configure Apple Developer Secrets</name>
  <action>
User must configure the three Apple Developer secrets in Firebase.

**Prerequisites:**
- Apple Developer Program enrollment complete ($99/year)
- MusicKit key created in Apple Developer Portal
- .p8 private key file downloaded (one-time download, save it securely)
  </action>
  <what-needed>
The user needs to run these commands with their Apple Developer credentials:

```bash
# Set Team ID (10-character alphanumeric from Membership page)
firebase functions:secrets:set APPLE_TEAM_ID
# Paste Team ID when prompted (e.g., ABC1234567)

# Set Key ID (10-character alphanumeric from Keys page)
firebase functions:secrets:set APPLE_KEY_ID
# Paste Key ID when prompted (e.g., DEF8901234)

# Set Private Key (entire .p8 file contents including headers)
firebase functions:secrets:set APPLE_PRIVATE_KEY
# Paste entire .p8 file content including:
# -----BEGIN PRIVATE KEY-----
# MIGT...
# -----END PRIVATE KEY-----
```

**Where to find these values:**
- Team ID: https://developer.apple.com/account -> Membership -> Team ID
- Key ID: https://developer.apple.com/account/resources/authkeys/list -> Your MusicKit key
- Private Key: Downloaded .p8 file when you created the MusicKit key

**If you don't have a MusicKit key yet:**
1. Go to https://developer.apple.com/account/resources/authkeys/list
2. Click "Create a key"
3. Name it (e.g., "Album Anniversaries MusicKit")
4. Check "MusicKit" checkbox
5. Click "Continue" then "Register"
6. Download the .p8 file (SAVE IT - you can only download once!)
7. Note the Key ID shown on the page
  </what-needed>
  <resume-signal>
Type "secrets configured" after running all three firebase functions:secrets:set commands successfully.
  </resume-signal>
</task>

<task type="auto">
  <name>Task 3: Validate token against Apple Music API</name>
  <files>(no file changes)</files>
  <action>
Call the deployed function and validate the returned token against Apple's test endpoint.

**Step 1: Get a token from the function**

The function is a Firebase callable function. We can test it using curl with the Firebase REST API format:

```bash
# Get the project ID
PROJECT_ID=$(firebase use 2>&1 | grep -oE '\([^)]+\)' | tr -d '()')

# Call the function (callable functions use a specific format)
curl -X POST \
  "https://us-central1-${PROJECT_ID}.cloudfunctions.net/getAppleMusicToken" \
  -H "Content-Type: application/json" \
  -d '{"data":{}}' 2>&1
```

Expected response format:
```json
{"result":{"token":"eyJhbGciOiJFUzI1NiIsInR5cCI6IkpXVCIsImtpZCI6IkRFRjg5MDEyMzQifQ..."}}
```

**Step 2: Validate token against Apple Music API**

Extract the token and test it:

```bash
# Save token from previous response (replace TOKEN with actual value)
TOKEN="eyJ..."

# Test against Apple Music API test endpoint
curl -s -o /dev/null -w "%{http_code}" \
  -H "Authorization: Bearer ${TOKEN}" \
  "https://api.music.apple.com/v1/test"
```

Expected: HTTP 200 (success)

**Step 3: Decode and verify token claims**

```bash
# Decode JWT payload (middle part)
echo "${TOKEN}" | cut -d. -f2 | base64 -d 2>/dev/null | python3 -m json.tool
```

Expected claims:
- `iss`: Your Team ID (e.g., "ABC1234567")
- `iat`: Unix timestamp (recent)
- `exp`: Unix timestamp (~180 days from iat)
- No other claims (no aud, sub, etc.)

**Troubleshooting:**
- 401 Unauthorized: Token has wrong claims or invalid signature
- 403 Forbidden: Key may not have MusicKit permission
- Connection error: Check function deployment status
  </action>
  <verify>
The Apple Music API test endpoint returns HTTP 200:
```bash
curl -s -o /dev/null -w "%{http_code}" \
  -H "Authorization: Bearer ${TOKEN}" \
  "https://api.music.apple.com/v1/test"
```
Should output: 200
  </verify>
  <done>
- getAppleMusicToken function returns a valid JWT
- JWT contains correct claims (iss=Team ID, iat, exp only)
- Apple Music API test endpoint accepts the token (HTTP 200)
  </done>
