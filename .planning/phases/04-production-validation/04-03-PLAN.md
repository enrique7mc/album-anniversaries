## Desktop Browser Testing

1. **Open production site**: https://album-anniversaries.firebaseapp.com/
2. **Test Spotify login**:
   - Click "Sign in with Spotify"
   - Complete authorization
   - Verify albums load and display correctly
   - Click logout, verify success message appears
3. **Test Apple Music login**:
   - Click "Sign in with Apple Music"
   - Complete authorization popup
   - Verify albums load and display correctly
   - Note: If popup is blocked, verify error message appears
4. **Test provider switching**:
   - Login with Spotify, then logout
   - Login with Apple Music
   - Verify no stale Spotify data appears

## Real iPhone/iPad Testing (REQUIRED)

**Prerequisites:**
- iPhone or iPad with iOS 15+
- Apple Music subscription
- Safari browser (not Chrome)

**Testing steps:**

1. **Connect iPhone to same WiFi as Mac**

2. **Open Safari on iPhone** and navigate to:
   https://album-anniversaries.firebaseapp.com/

3. **Test Apple Music login**:
   - Tap "Sign in with Apple Music"
   - Authorization popup should appear
   - Complete sign-in
   - Verify albums load

4. **Test error handling scenarios**:
   - If you have a non-subscriber account, try logging in
     - Should show "Apple Music subscription required" error
   - If popup is blocked, should show popup blocked message

5. **Enable Safari Web Inspector for debugging** (optional):
   - iPhone: Settings → Safari → Advanced → Web Inspector ON
   - Mac: Safari → Develop → [Your iPhone] → [Page]
   - Check console for any errors

6. **Test Private Browsing** (if time permits):
   - Open Safari Private Browsing mode
   - Navigate to the production URL
   - Attempt Apple Music login
   - Should show warning about Private Browsing
