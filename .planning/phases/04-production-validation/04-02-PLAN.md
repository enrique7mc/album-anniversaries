  <action>
Update firebase.json with comprehensive hosting configuration:

1. Fix the public directory path:
   - Current: "dist/spotify-demo" (incorrect)
   - Should be: "dist/album-anniversaries/browser" (Angular 17 output path)
   - Verify by checking angular.json for actual output path

2. Add cache headers for optimal performance:
   - Static assets (images): `max-age=31536000` (1 year)
   - JS/CSS bundles: `max-age=31536000` (1 year, fingerprinted by Angular)
   - index.html: `no-cache, no-store, must-revalidate` (always fetch fresh)

3. Add security headers:
   - X-Content-Type-Options: nosniff
   - X-Frame-Options: DENY
   - Referrer-Policy: strict-origin-when-cross-origin

4. Keep existing rewrites for SPA routing

The complete firebase.json should be:
```json
{
  "hosting": {
    "public": "dist/album-anniversaries/browser",
    "ignore": ["firebase.json", "**/.*", "**/node_modules/**"],
    "rewrites": [
      {
        "source": "**",
        "destination": "/index.html"
      }
    ],
    "headers": [
      {
        "source": "**/*.@(jpg|jpeg|gif|png|svg|webp|ico)",
        "headers": [
          { "key": "Cache-Control", "value": "max-age=31536000" }
        ]
      },
      {
        "source": "**/*.@(js|css)",
        "headers": [
          { "key": "Cache-Control", "value": "max-age=31536000" }
        ]
      },
      {
        "source": "index.html",
        "headers": [
          { "key": "Cache-Control", "value": "no-cache, no-store, must-revalidate" }
        ]
      },
      {
        "source": "**",
        "headers": [
          { "key": "X-Content-Type-Options", "value": "nosniff" },
          { "key": "X-Frame-Options", "value": "DENY" },
          { "key": "Referrer-Policy", "value": "strict-origin-when-cross-origin" }
        ]
      }
    ]
  },
  "functions": {
    "source": "functions",
    "runtime": "nodejs20"
  }
}
```
