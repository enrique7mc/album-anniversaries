  <how-to-verify>
**Pre-requisite:** HTTPS localhost must be set up. If not already done:
```bash
# Option 1: Angular CLI built-in HTTPS (may show certificate warning)
ng serve --ssl

# Option 2: Use mkcert for trusted certificates
brew install mkcert
mkcert -install
mkcert localhost 127.0.0.1
ng serve --ssl --ssl-key localhost+1-key.pem --ssl-cert localhost+1.pem
```

**Testing steps:**

1. Start dev server with HTTPS:
   ```bash
   npm start -- --ssl
   ```
   Navigate to https://127.0.0.1:4200 (accept certificate warning if needed)

2. Verify landing page shows both sign-in buttons:
   - Spotify button (green)
   - Apple Music button (red) - should NOT show "Coming Soon" badge

3. Click "Sign in with Apple Music" button:
   - MusicKit should initialize (may take 1-2 seconds)
   - Apple Music authorization popup should appear
   - Sign in with your Apple Music account

4. After successful authorization:
   - Loading state should show
   - Your Apple Music library artists should load
   - Album anniversary cards should display

5. Verify data display:
   - Artist cards show names and images
   - Album cards show artwork, name, release date
   - Anniversary filtering works (This Week / This Month / Last Year)

6. Test logout and provider switching:
   - Log out (if logout button exists, otherwise refresh)
   - Sign in with Spotify to verify it still works
   - Sign in with Apple Music again

**Expected behavior:**
- Both providers show the same UI/UX for album anniversaries
- Apple Music shows library artists (alphabetical, not "top artists")
- Images load correctly from Apple Music CDN
- Anniversary date filtering works identically to Spotify
  </how-to-verify>
