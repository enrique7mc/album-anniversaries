<task type="auto">
  <name>Task 2: Implement data fetching and response mapping</name>
  <files>src/app/services/apple-music.service.ts</files>
  <action>
Add data fetching methods to AppleMusicService:

1. Implement loadArtistsWithAlbums(accessToken: string): Observable<boolean>
   - This is the MusicService interface method
   - For Apple Music, accessToken is the Music User Token (can be ignored if already authorized)
   - Calls private fetchAllLibraryArtists()
   - For each artist, calls fetchAlbumsForArtist()
   - Maps responses to Artist[] and emits via artistsSubject
   - Returns Observable that emits true on success, false on error

2. Implement private fetchAllLibraryArtists(): Promise<any[]>
   - Uses MusicKit passthrough: musicKitInstance.api.music('/v1/me/library/artists', { limit: 100 })
   - Handles pagination via 'next' property (NOT manual offset calculation)
   - Returns all library artists (no "top artists" equivalent in Apple Music)

3. Implement private fetchAlbumsForArtist(artistId: string): Promise<any[]>
   - Uses catalog endpoint: /v1/catalog/us/artists/{artistId}/albums
   - Hardcode 'us' storefront for v1 (noted in research as acceptable)
   - Limit 100 albums per artist
   - Add rate limiting: use batching with 200ms delay between batches of 5 requests

4. Implement private mapToArtist(resource: any): Artist
   - Map id, name, href from resource
   - Map artwork to images using mapArtwork()
   - Set popularity to 0 (Apple Music doesn't provide)
   - Set external_url from resource.attributes.url
   - Initialize albums as empty array

5. Implement private mapArtwork(artwork: any): Image[]
   - Handle null/undefined artwork (return empty array)
   - Apple Music artwork uses template: {w}x{h} placeholders
   - Generate 3 sizes: 640x640, 300x300, 64x64
   - Return Image[] matching existing interface

6. Implement private mapToAlbum(resource: any, artistId: string): Album
   - Map id, name from resource.attributes
   - Set artist_id from parameter
   - Map release_date from resource.attributes.releaseDate (YYYY-MM-DD format)
   - Set release_date_precision to 'day' (Apple always provides day precision)
   - Map artwork to images
   - Set external_url from resource.attributes.url

Important implementation notes from research:
- Use api.music() passthrough method, NOT deprecated v1 endpoint-specific methods
- Pagination: always use 'next' property from response, not manual offset
- Rate limiting: batch requests to avoid potential throttling
- Handle errors gracefully (try/catch around API calls)
