Create MusicKitLoaderService at src/app/services/musickit-loader.service.ts:

1. Injectable service with providedIn: 'root'
2. Private loadPromise: Promise<void> | null for singleton pattern
3. loadMusicKit(): Promise<void> method that:
   - Returns existing loadPromise if already loading/loaded (singleton)
   - Checks if window.MusicKit already exists (early return)
   - Adds 'musickitloaded' event listener BEFORE creating script element
   - Creates script element with src: 'https://js-cdn.music.apple.com/musickit/v3/musickit.js'
   - Sets async = true
   - Adds onerror handler that rejects with descriptive error
   - Appends script to document.body
   - Resolves promise when 'musickitloaded' event fires

Important: The 'musickitloaded' event listener must be added BEFORE appending the script to avoid race conditions.

Create basic unit tests at src/app/services/musickit-loader.service.spec.ts:
